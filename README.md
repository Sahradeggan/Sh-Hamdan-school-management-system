# 🎓 Sh Hamdan School Management System

A modern **School Management System** built using **HTML, CSS, and JavaScript (LocalStorage based)**.
This system is designed for managing school operations in a simple and offline-friendly way.

---

## 📌 Features

* 👨‍💼 Admin-only dashboard system
* 👨‍🎓 Student management (Add, Edit, Delete, Search)
* 👨‍🏫 Teacher management system
* 🏫 Class management
* 📝 Attendance tracking
* 📊 Results / Grades system
* 💰 Fees management
* 📈 Dashboard statistics with charts (Bar + Pie)
* 👤 Admin profile view
* 💾 Data stored using **LocalStorage (no backend required)**

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Modern UI Design)
* JavaScript (Vanilla JS)
* Chart.js (for dashboard analytics)
* LocalStorage (for data persistence)

## 🚀 How to Run the Project

1. Download or clone the project
2. Open `index.html` in your browser
3. Login as admin (if login system is enabled)
4. Start managing students, teachers, and records

---

## 💾 Data Storage

This project uses **LocalStorage**, meaning:

* Data is stored in your browser
* No server or database required
* Data remains until browser cache is cleared
